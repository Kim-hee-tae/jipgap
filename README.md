# 집값 점수판 (jipgap)

국토교통부 실거래가로 보는 **지역별 1년 상승률 · 가장 많이 오른 아파트 · 수요/공급/시황 점수**.
kairu-kit(자동 새로고침, JSON 저장, 서비스 워커, EC2 배포) 기반.

## 화면
- 전국 / 시도 / 시군구 탭 + 지역 검색, 관심 지역(☆, 이 브라우저에 저장)
- **매매 환경 요약**: 수요·공급·시황 트리맵, 평당가와 투자점수 추이
- **가장 많이 오른 하위 지역**: 전국→시도, 시도→시군구, 시군구→동 (트리맵 + 순위, 누르면 이동)
- **가장 많이 오른 아파트**: 평형대(20평대 이하 / 20평대 / 30평대 / 40평대 이상) 선택
- **지표 모아보기**: 지표별 점수·추세·스파크라인

## 계산 방법
| 항목 | 방법 |
|---|---|
| 평당가 | 거래금액 ÷ (전용면적 ÷ 3.3058), 3개월 묶음 중앙값 |
| 1년 상승률 | 같은 단지·같은 평형대의 최근 6개월 vs 1년 전 6개월 중앙값 → 거래 수 가중 중앙값 |
| 지표 점수 | 지금 값이 그 지표 과거 기록에서 몇 % 위치인지 → 1~10점 (금리·미분양은 낮을수록 높은 점수) |
| 카테고리·종합 | 지표 점수 평균 → 카테고리 평균 |

지표: 수요(매매 거래량, 전세가율, 주담대 금리, 기준금리) · 공급(미분양) · 시황(3개월 가격 흐름, 1년 가격 변화, 거래량 흐름)

## 데이터 키 (.env)
키가 없으면 **데모 데이터**로 돈다 (화면 위에 데모 표시).

| 변수 | 어디서 | 비고 |
|---|---|---|
| `MOLIT_KEY` | [공공데이터포털](https://www.data.go.kr) | 「국토교통부_아파트 매매 실거래가 자료」와 「아파트 전월세 실거래가 자료」 둘 다 활용신청. 인코딩/디코딩 키 아무거나 |
| `ECOS_KEY` | [한국은행 ECOS](https://ecos.bok.or.kr/api/) | 기준금리 722Y001/0101000, 주담대 121Y006/BECBLA0302 (`ECOS_SERIES` 로 바꿀 수 있음) |
| `KOSIS_UNSOLD_URL` | [KOSIS](https://kosis.kr) | 「미분양주택현황」 표 → 시도별·월별로 골라 OpenAPI URL(JSON) 생성 → URL 통째로 |
| `BACKFILL_MONTHS` | | 받을 기간 (기본 36개월) |
| `MOLIT_DAILY_LIMIT` | | API별 하루 최대 호출 (기본 9000, 개발계정 한도 안쪽) |

처음 키를 넣으면 전국 254개 시군구 × 36개월을 받느라 하루 정도 걸린다 (한도에 걸리면 다음 날 이어서). 이후엔 매일 06시 이후 최근 3개월만 다시 받는다.

## 실행
```bash
npm install
npm start                 # http://localhost:3020 — 데이터 없으면 처음에 자동으로 만듦
npm run demo              # 데모 데이터 다시 만들기
npm run update            # 지금 바로 수집 + 집계
npm run build             # 수집 없이 집계만
npm test                  # 점검
```

## 배포 (kit deploy)
`app.config` — APP_NAME `jipgap`, PORT `3020`. 서버에서 `git clone` → `bash deploy.sh` (키 3개를 물어보고, 엔터면 데모).
이후 push 하면 5분 안에 자동 배포 → `https://jipgap.<IP>.sslip.io`.
내 도메인은 `deploy.domain` 파일에 한 줄 (예: `jipgap.yplue.com`) + Cloudflare A 레코드(회색 구름).
